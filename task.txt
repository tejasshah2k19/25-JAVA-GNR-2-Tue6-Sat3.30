A Java: Addition Magic Language Method overloading allows a class to have multiple methods with the same name but different argument lists. Using method overloading, complete the implementation of the class AdditionMagic with 3 methods. 1. public String add ( double a, String b) => add(1, "hello") →> returns "Thello" 2. public String add(double a, double b) => add(1.1,2.2) => returns 3.3 (rounded to 2 decimal places) • Examples of rounding (3.765 => 3.77, 3.7649 =>3.76, 3.778 => 3.79) 3. public String add(String a, String b) => add("Hello,""world!") => returns "Hello,world!" When code is submitted, the provided Solution class will test the add methods with different arguments. Example Suppose inputs are: 4 12 34 1 hello hello, world Output: 3.0 7.0 Thello hello,world Explanation: The first row tells how many pairs there are. It is only used by the code stub. Pairs of values are read and passed to the method.
* 1+2 = 3.0

* 3 + 4 = 7.0

* 1 + "hello" = "Thello"

* "hello," + "world" = "hello,world"
